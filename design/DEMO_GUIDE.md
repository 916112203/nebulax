# SmartPipe GIS 演示指南（约 10 分钟）

> 适用于面试演示、项目汇报、课程展示。建议提前按本指南操作一遍熟悉路径。
> 在线模式与演示模式（GitHub Pages）操作完全一致。

## 演示前准备

1. **在线模式**：确保后端已启动（`curl http://localhost:8080/api/overview/health` 返回 ok），打开 `http://localhost:5173`（开发）或 `http://<虚拟机IP>/`（部署）；
2. **演示模式**：直接打开 GitHub Pages 地址即可（登录页会显示"演示模式"徽标）；
3. 演示账号：`admin / admin123`（完整权限，推荐）。

## 演示路径

### 第 1 幕 · 登录与角色（1 分钟）

1. 点击演示账号快速填充，用 `admin/admin123` 登录；
2. 介绍 4 级角色权限设计（可退登后用 `wangfang/wang123` 登录，展示只读用户看不到"新增/编辑"按钮）。

### 第 2 幕 · 综合大屏（1.5 分钟）

1. 讲解 KPI 指标卡：管网总长 148 km、753 座井、告警与传感器在线情况；
2. 指向"近 7 天告警趋势"与"管线类型分布"——强调**图表与地图同色图例一致**；
3. 底部"实时监测"切换传感器与时间范围（1h/6h/24h），指出红色虚线为告警阈值；
4. 停留 30 秒：实时曲线持续刷新（3s 数据流）。

### 第 3 幕 · 一张图（3 分钟，核心）

1. 图层开关：逐层演示管线/井/泵站/建筑/传感器；
2. **搜索定位**：搜索"中山大道"→ 地图自动缩放，黄色高亮 10 个匹配要素；
3. **属性查询**：点击任意管线 → 右侧抽屉显示完整属性（管径/埋深/材质/敷设年份/起止井）；
4. **空间分析**（抽屉内"空间分析"按钮）：
   - 500m 缓冲查询 → 高亮周边要素；
   - 上游/下游追踪 → 高亮连通路径；
   - **爆管关阀分析** → 展示关阀方案、受影响管段（红色高亮）、影响户数、6 步处置流程——这是最能体现 GIS 专业性的功能；
   - 管线纵剖面 → 地面线 + 管底线断面图；
5. **专题图**：切换"按管径分级 / 按埋深分级 / 按敷设年代"，说明分级设色规范；
6. **量测工具**：地图上画线量距、画面量面积；
7. **编辑要素**（体现前后端交互）：编辑一条管线属性（如修改状态为"维修中"）→ 保存 → 刷新后仍在（后端持久化）；
8. 左下角"实时监测"卡片：传感器值每 3s 刷新，出现红色闪烁说明该传感器越限。

### 第 4 幕 · 实时告警闭环（1.5 分钟）

1. 停留等待（或主动演示）：遥测模拟器随机注入异常 → 右上角弹出红色告警通知（在线模式每 1~2 分钟一次）；
2. 进入**告警中心**：按级别/状态筛选，演示"受理 → 关闭"处置流程（填写处置结果）；
3. 点击告警"地图定位"→ 跳转一张图并自动缩放高亮告警设施。

### 第 5 幕 · 工单与巡检（1.5 分钟）

1. **工单管理**：展示五状态流转（打开详情看 el-steps 进度），演示"流转 → 完成（填写作业结果）"；新建一张抢修工单并关联管线；
2. **巡检管理**：打开"2026年8月污水管网日常巡检"（进行中）→ 展示点位状态（绿=正常/红=异常），演示上报一个异常点位 → 提示"已生成告警工单"→ 回到告警中心看到新告警；
3. 新建巡检计划（选择点位）或在地图查看巡检路线（紫色虚线 + 点位状态）。

### 第 6 幕 · 管网分析中心与收尾（1.5 分钟）

1. **连通性追踪**：任选管线做上下游追踪，展示结果表格；
2. **爆管关阀分析**：选给水管线（如 GS-DN400-07）→ 讲解"上游阀门/下游阀门/隔离边界阀门"三级关阀方案与影响户数估算——点出这是供水管网 GIS 的经典功能；
3. **用户管理**（admin）：新增一个用户、演示角色下拉；
4. 收尾：说明技术架构（前后端分离、REST+WebSocket、SQLite、Docker/Nginx/systemd 三种部署）、数据同源设计、GitHub Pages 演示模式。

## 面试高频追问与应答要点

| 追问 | 应答要点 |
|---|---|
| 数据怎么来的？ | 确定性种子随机生成器（mulberry32 PRNG），参考真实路网格局与普查成果结构设计；道路交叉口强制布井 + 30m 同类型合并 → 84 个共享节点，形成真实拓扑 |
| 爆管关阀怎么算的？ | 拓扑图 BFS：爆管段两侧最近隔离点 + 分层阀门阻断 + 120m 缓冲估算影响建筑/户数 |
| 为什么用 sql.js？ | SQLite WASM 零原生依赖，规避 node-gyp/glibc 部署问题；业务数据 5s 落盘、遥测表内存化 + 72h 清理 |
| 前端怎么做到 GitHub Pages 零后端？ | API 双模式门面：启动探测 health，失败回退浏览器内存引擎（数据同源、逻辑同构）；演示模式遥测由本地模拟器生成 |
| 实时推送怎么做的？ | WebSocket 单帧批量推送 31 传感器读数；异常注入 → 告警事件广播 → 前端全局弹窗 + 地图闪烁 |
| 权限怎么控制？ | JWT + 4 角色矩阵，后端接口级 401/403，前端路由守卫 + 按钮级控制（演示模式同构） |
| 后续可以做什么？ | 真实坐标接入（CGCS2000）、PostGIS 迁移、轨迹回放、爆管影响三维可视化、多租户 |

## 演示故障排查

| 现象 | 处理 |
|---|---|
| 地图底图空白 | 需访问互联网（天地图在线服务）；网络受限时说明可切换离线底图 |
| 一直显示"演示模式" | 后端未启动或 nginx 反代未生效，见 [部署指南](../deploy/DEPLOY.md) 常见问题 |
| 没有实时弹窗 | 等 1~2 分钟（异常注入周期），或降低 `ANOMALY_CHANCE` 后重启后端 |
| 数据被演示改乱了 | 删除 `server/data/smartpipe.db` 重启后端自动重建；演示模式刷新页面即恢复 |
